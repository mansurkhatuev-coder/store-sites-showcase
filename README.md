# Макеты сайтов

Один проект содержит три самостоятельных макета. Страницы не ссылаются друг на друга — каждый сайт можно открыть и отправить клиенту по отдельному адресу.

| Макет | Ссылка |
| --- | --- |
| BAKHURRR — Creed Aventus, 10 мл | https://mansurkhatuev-coder.github.io/store-sites-showcase/ |
| KADO — ресторанное меню | https://mansurkhatuev-coder.github.io/store-sites-showcase/kado/ |
| КРЕМ — кондитерская витрина | https://mansurkhatuev-coder.github.io/store-sites-showcase/krem/ |

## Структура

- `public/` — BAKHURRR на главном адресе проекта.
- `public/kado/` — отдельная страница KADO.
- `public/krem/` — отдельная страница КРЕМ.
- `public/assets/` — видео и стартовый кадр главного экрана BAKHURRR.

GitHub Pages публикует содержимое `public/` после отправки изменений в `main`.

Для кнопки WhatsApp BAKHURRR нужен номер продавца: поле `whatsappPhone` в `public/config.js` пока пустое. Ссылки на Wildberries и Instagram уже настроены.
